# HUSH (retired)

The first game built on these concepts: a night garden where flowers open as they get thirsty and close as they
wilt, and an Owl who seals calm flowers under glass. The requester found it neither fun nor comprehensible; the
diagnosis is in [`docs/process-v2/11-redesign.md`](../../docs/process-v2/11-redesign.md), and the build notes are in
[`08-build.md`](../../docs/process-v2/08-build.md).

Kept for reference. The sources were moved here unchanged, so the tools' relative paths (`../src/...`) refer to the
old layout. `dist-hush.html` is the last playable build.
